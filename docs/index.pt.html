Luma

Um mixer de áudio multipista para Linux. Reproduz várias faixas ao mesmo tempo e controla cada uma à tua maneira: volume, balanço, fades, efeitos e mais.

O que é o Luma

O Luma é como uma mesa de mistura no teu computador. Cada faixa de áudio (uma música, um efeito sonoro, uma locução…) fica no seu próprio canal, e tu decides como soa e quando: subir ou baixar o volume, movê-la para a esquerda ou direita, aplicar efeitos, fazê-la aparecer ou desaparecer, e enviá-la para umas colunas ou outras.

Foi pensado para diretos, rádio, teatro, eventos ou qualquer situação em que precises de lançar e misturar vários áudios de forma fiável. Não precisas de conhecimentos técnicos: este guia leva-te passo a passo.

1Primeiros passos

Ao abrir o Luma pela primeira vez verás o ecrã de boas-vindas. Aqui escolhes com o que trabalhar:

  • Novo projeto: cria um projeto vazio. Dá-lhe um nome e escolhe onde guardá-lo.
  • Abrir projeto: abre um projeto que já tens.
  • Projetos recentes: acesso rápido ao que abriste por último. O ✕ de cada linha remove-o da lista (com confirmação; não apaga nada do teu disco, apenas o atalho).
  • Acerca de: informação sobre a aplicação (versão, licença).

Da próxima vez, o Luma reabre automaticamente o último projeto em que trabalhaste (podes mudar isto nas Preferências).

2Projetos

Um projeto guarda todo o teu trabalho: as faixas, as definições de cada canal, os presets e os fluxos. Cada projeto é uma pasta que podes copiar, mover ou levar para outro computador sem receio.

O importante: quando adicionas uma faixa, o Luma guarda uma cópia dentro do projeto. Assim, mesmo que apagues ou movas o ficheiro original, o projeto continua a soar igual. A pasta é autónoma e portável.

Se fizeres duplo clique num ficheiro .luma no teu gestor de ficheiros, abre diretamente no Luma.

3A janela principal

O ecrã divide-se em três zonas:

  • Em cima: a barra com o projeto, o volume geral e os presets.
  • À esquerda: a lista de faixas (em cima) e a lista de fluxos (em baixo).
  • À direita: os canais, onde fazes a mistura.
Podes mover a janela arrastando qualquer zona livre da barra superior, e redimensioná-la pelas margens.

4A barra superior

  • PROJECTS: fecha o projeto atual e volta ao ecrã de boas-vindas.
  • MASTER: o volume geral de toda a mistura, com o seu medidor de nível.
  • PANIC: o botão de emergência. Para todo o áudio de imediato.
  • Botões de opções: saídas de áudio, número de canais, reordenar, grelha e preferências.
  • Botões de preset (P1…P10): alterna entre as tuas cenas guardadas.

5Lista de faixas

É a biblioteca de áudios do teu projeto (canto superior esquerdo).

  • Adicionar ficheiros: importa áudios em formato WAV, MP3, OGG ou FLAC. Ordenam-se sozinhos por ordem alfabética.
  • De cada faixa vês o nome, a duração, o formato e em que canais está a ser usada.
  • Para usar uma faixa: arrasta-a para um canal, ou usa o seu menu e escolhe Bind para a atribuir.
  • O menu também tem Remove para a retirar (com confirmação; apaga a cópia do projeto).

6Os canais

Cada canal é uma coluna que reproduz uma faixa. De cima para baixo tens:

  • Barra de cor e nome (duplo clique para renomear). A cor ajuda a identificar os canais num relance.
  • Balanço: move o som para a esquerda ou a direita.
  • Volume: o cursor grande, com o seu medidor de nível. Tem dois marcadores que definem até onde sobem ou descem os fades.
  • Fades: botões para a faixa aparecer (fade in) ou desaparecer (fade out) suavemente. Podes definir a duração em segundos e o tipo de curva.
  • AUX: envia este canal para a saída auxiliar em vez da principal.
  • Efeitos e Equalizador: abrem os seus painéis (secções 7 e 8). Acendem quando estão ativos.
  • Repetição: reproduz a faixa em ciclo.
  • Reproduzir / Pausa e Parar.
  • Barra de progresso: mostra onde vai a faixa; clica para recortar a parte a reproduzir (secção 9).
Clica com o botão direito num canal para atribuir ou retirar a faixa e mudar a cor rapidamente.

7Efeitos

Cada canal tem cinco efeitos que podes ativar em separado. Cada um lembra os seus valores mesmo desligado, e há um botão para voltar aos valores predefinidos.

8Equalizador

O equalizador permite realçar ou atenuar diferentes frequências do som: os graves, os médios e os agudos. Tem 10 bandas (de 32 Hz a 16 kHz), cada uma ajustável até ±12 dB.

Por exemplo: baixa as bandas mais baixas para tirar o ronco, ou sobe as altas para mais brilho.

9Recortar uma faixa

Se só quiseres reproduzir uma parte de uma faixa, clica na sua barra de progresso. Abre-se uma janela onde podes:

  • ver a duração total e a posição atual.
  • marcar um início e um fim para reproduzir só essa parte.
  • limpar o recorte de início ou de fim, ou repor a faixa completa.

10Presets (cenas)

Um preset é um instantâneo completo de toda a mesa: que faixa tem cada canal, os volumes, efeitos, cores… Tens 10 presets (P1 a P10) por projeto.

Servem para preparar diferentes momentos de um evento. Por exemplo: P1 para a entrada do público, P2 para o ato principal, P3 para o encerramento. Mudas de um para outro com um clique.

Ao mudar de preset para a reprodução atual (com confirmação) e o Luma guarda automaticamente o estado do preset que deixas, para não perderes nada.

11Fluxos

Os fluxos automatizam a reprodução: em vez de lançar cada faixa à mão, defines uma sequência e o Luma executa-a por ti. Ideal para encadear áudios com transições suaves.

Criar um fluxo

Na lista de fluxos (canto inferior esquerdo) carrega em New flow. Abre-se um editor com uma tela onde montas a sequência como um pequeno mapa:

  • Adicionar passos: clica num canal da lista para o colocar na tela como um «nó». O mesmo canal pode aparecer várias vezes.
  • Ligá-los: arrasta do ponto de saída de um nó até ao seguinte para os ligar. O ponto START marca o início.
  • Mover-te pela tela: arrasta o fundo ou usa a roda; Ctrl + roda para ampliar/reduzir.

Configurar cada passo

Faz duplo clique num nó para decidir como deve soar esse canal quando o fluxo o ativa (volume, fade, ciclo, ponto de início, efeitos…).

Clica numa ligação para decidir quando passa ao passo seguinte e o que acontece:

  • Disparador: de imediato, ao fim de alguns segundos, ou quando a faixa anterior termina.
  • Na origem: não fazer nada, fade out ou parar.
  • No destino: reproduzir diretamente ou entrar com um fade in.

Executar

Carrega em Run para lançar o fluxo. Os canais envolvidos mostram um contorno intermitente para os identificares, e podes continuar a usar a mesa enquanto corre. O fluxo termina sozinho, com Stop ou com PANIC; no fim, os canais voltam ao estado anterior.

12Saídas de áudio

O Luma pode enviar o som para duas saídas diferentes:

  • Main: para onde vai a maioria dos canais.
  • Aux: para onde vão os canais com o botão AUX ativado.

Na janela de saídas escolhes que dispositivo usa cada uma (por exemplo, colunas para o público e auscultadores para ti), ou deixas o dispositivo predefinido do sistema.

13Definições da mesa

  • Número de canais: escolhe quantos canais queres (de 1 a 40). Se reduzires o número, és avisado de que perderás a configuração dos últimos.
  • Reordenar canais: ativa um modo para mudar a ordem dos canais.
  • Modo grelha: dispõe os canais em duas filas, útil quando são muitos.

14Preferências

  • Abrir o último projeto ao arrancar: ativa ou não a retoma automática do teu trabalho.
  • Idioma: muda o idioma da interface (aplicado após reiniciar). Disponível em inglês, espanhol, francês, alemão, italiano, português e neerlandês.
  • Tamanho da cache de áudio e reaquecer cache: definições de desempenho para que as faixas soem sem atrasos.
  • Atalhos de teclado: podes reatribuir qualquer atalho. Carrega no seu botão e depois na combinação de teclas que preferires.
